# SIMPLIFY CRM

Modern, AI-powered CRM platform built on Lovable.

**Project URL**: https://lovable.dev/projects/0fb8cac4-5135-4759-97bb-fbe5ff382073

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Lovable Cloud (managed Supabase backend)

## Local development

```sh
npm i
npm run dev
```

## Deployment

Open the Lovable project and click **Share → Publish**. Custom domains can be configured under **Project Settings → Domains** after publishing.
